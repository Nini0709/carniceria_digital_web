Documentación Técnica y Funcional

Proyecto web académico Carnicería Digital desarrollado con HTML5, Bootstrap 5.3, JavaScript, PHP y MySQL/MariaDB.

1. Arquitectura del Sistema

  • Front-End: Interfaces responsivas en HTML5 y Bootstrap 5.3 (index.html, productos.html, tutorial.html, registro.html) con estilos personalizados en css/estilos.css y filtros en js/app.js.
  • Back-End: Scripts PHP con consultas preparadas (mysqli_prepare) en conexion.php, comprar.php, guardar_compra.php, confirmacion.php y listar_compras.php.
  • Base de Datos: Esquema digitalcarniceria_db definido en Base de datos C.D.sql con tablas relacionadas para clientes, empleados, categorías, productos, ventas, pedidos y pesaje en báscula.

2. Flujo de Compra y Persistencia

  1. El usuario explora los cortes en index.html o productos.html y consulta recomendaciones en tutorial.html.
  2. En comprar.php (o guardar_compra.php), se valida el corte, el peso en kilogramos y el stock disponible, se registra o recupera el cliente en cliente y se crean los registros en pedidos y detalle_pedido.
  3. Se actualiza el stock_disponible del producto y se redirige a confirmacion.php para mostrar el comprobante calculado desde la base de datos.
  4. Los pedidos guardados pueden revisarse en listar_compras.php.
